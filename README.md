# 便宜香港 VPS：DMIT 香港套餐怎么挑，$6.9/月起把预算花在真正影响速度的线路上

香港 VPS 的价格里，硬件占比其实很小。同样 1 核 1G 的机器，放在美国可能一年 $15，放在香港就要 $30 往上，差价基本全在带宽和机房上。所以"便宜香港 VPS"这个问题，本质是另一个问题：你愿意在哪部分网络质量上让步。

先把三条常见的香港线路摆出来，后面挑套餐就简单了。

- **国际 BGP / 163 类线路**：接入 NTT、PCCW、Cogent 等国际运营商，面向海外用户很快，回中国大陆可能绕日本、新加坡甚至美国，晚高峰延迟飙到 150–300ms 不稀奇。
- **CMI（中国移动国际）**：回程走移动出口，国内可用性比纯国际线路好一截，成本又比 CN2 GIA 低不少，近两年是性价比路线的主力。
- **CN2 GIA**：电信 59.43 段的高优先级承载网，双程精品，国内延迟 30–45ms 是常态，带宽采购成本是普通国际带宽的数倍。

反过来看，那些月付一两美元的香港 VPS 通常是什么：1–5Mbps 小水管、NAT 共享 IP，或者干脆标着香港、实际绕美。判断方法不复杂——下单前找到测试 IP 自己 ping 和 traceroute 一遍，比看十页宣传文案都有用。

## Eyeball 这条线，现在的情况比较乱

Eyeball 的定位是 Tier 1 之上、Premium 之下，回程主要走 CMI，去程电信走 CN2、联通和移动走 NTT 一类线路，属于"移动用户体感不错、但路由不保证"的档位。

问题在于它的公开信息前后矛盾得厉害。第三方记录里，EB 入门款出现过 $17.9/月、$24.9/月、$29.9/月、$39.9/月好几个版本（对应不同代平台和不同时期的促销）；一边有停产通知说 HKG EBv2 产品线终止并对存量用户提供迁移折扣，一边又不断有补货上架的消息。价格和库存同时在高频调整，这是它最容易踩坑的地方。

所以如果你只是要一台便宜的香港机器，Tier 1 的价格体系稳定得多，可预期性更好。真想买 EB，建议先确认当前库存、线路说明和计费方向（EB 是双向计费，T1 是单向，这两个差别会直接影响你的实际可用流量）。

## 下单前，有三件事值得做

**第一，自己测线路。** 官方提供测试 IP：Premium 系列是 103.117.100.199，Tier 1 是 154.12.176.28，另有一个国际 Lite 线路测试 IP 103.135.248.120。用你实际运营商的网络 ping 一遍，再看回程路由里有没有 59.43 段（CN2 GIA 标志）或 AS58453（CMI 标志）。测试比任何宣传都可靠。

**第二，试优惠码。** DMIT 的优惠码大多绑定具体产品线和付款周期，第三方整理里出现过 T1 季付及以上 7 折（如 `202510_HKG_TYO_T1_30OFF_RECURRING`）、Pro 季付及以上 8 折（如 `202510_HKG_TYO_PRO_20OFF_RECURRING`）这类循环折扣码，也有来源表示当前没有公开有效优惠码、直接就是特价。优惠码的有效期说法不一致，正确做法是在结算页填进去点 Validate Code 验证——能打折就是赚，不能也不影响你继续下单。

**第三，确认换 IP 和退款的规则。** 关于香港 Pro 的换 IP 政策，不同来源记录不一致：有说法是 IP 被墙可免费换，每 15 天一次；也有说法是 $5/次、每 30 天限一次、且服务到期时间需超过 30 天。这种信息以工单回复为准，别照抄别人的总结。

## 几个常被问到的点

**香港 VPS 需要备案吗？** 不需要 ICP 备案，域名解析过去就能访问，这是香港机房相对国内机房最实际的差别。

**便宜香港 VPS 能用来建站吗？** 看配置和线路。Tier 1 的 1GB 档跑静态站、轻量 API 没问题，跑 WordPress 加插件建议从 2GB 起。Pro 的入门档内存同样只有 1GB，但国内访问体验明显更好，取舍在于你更在意内存还是延迟。

**为什么香港 VPS 普遍比美国贵？** 香港机柜租金和带宽采购成本都在亚太最高一档，CN2 GIA 这类精品带宽还要按峰值计费，成本自然摊到售价里。看到明显低于市场价的"香港直连"，先测路由。

**流量超了会怎样？** 分产品线。Tier 1 超量后降速不限量，50Mbps 到 1Gbps 视套餐而定，不会断流；Eyeball 是双向计费且以暂停为主；Premium 的流量额度更小，买之前把额度算进预算。

**机器经常缺货怎么办？** DMIT 的香港和洛杉矶优化线路确实存在长期缺货的情况，热门档位补货后很快卖完。如果你已经确定要哪一档，可以先把目标套餐页面收藏起来定期看库存，或者退一步选库存稳定的 TINY / STARTER 档。

买便宜香港 VPS 这件事，绕不开一个取舍：省钱和省心很难同时拿到。DMIT 在香港的定位不算最便宜，但它的价格体系公开、线路分层清楚、流量和带宽写得明白，用来做"便宜"和"能用"之间的那个参照点，比那些只标月付价格不写回程路由的产品靠谱。真要下单，先 ping 测试 IP，再验证优惠码，最后确认换 IP 规则——这三步花不了十分钟，能省掉后面大部分麻烦。
